## DEPLOYMENT TO NEIGHBORS

### Quick Deploy (Single Host)

1. Copy responder to neighbor:
   ```
   scp gl_peer_responder.py user@192.168.4.22:~/
   ```

2. Run on neighbor:
   ```
   ssh user@192.168.4.22
   python3 gl_peer_responder.py
   ```

3. Verify integration (back on this host):
   ```
   python3 gl_network_status.py
   ```

### Batch Deploy (All Neighbors)

Use the provided batch deployment script:

```bash
#!/bin/bash
NEIGHBORS="192.168.4.2 192.168.4.22 192.168.4.23 192.168.4.24 \
           192.168.4.42 192.168.4.45 192.168.4.46"

for IP in $NEIGHBORS; do
    echo "→ Deploying to $IP..."
    scp -o ConnectTimeout=2 gl_peer_responder.py user@$IP:~/ 2>/dev/null && \
    ssh -o ConnectTimeout=2 user@$IP \
        'nohup python3 ~/gl_peer_responder.py > /tmp/gl.log 2>&1 &' \
        2>/dev/null &
done

wait
echo "✓ Deployment complete. Waiting for discovery..."
sleep 35
python3 gl_network_status.py
```

## DATA FLOW

1. Local thermal sensors → gl_peer_mesh → gl_controller
2. gl_peer_mesh scans neighbors every 30s
3. When neighbors have responder running:
   - Query neighbor thermal data
   - Aggregate with local data
   - Calculate mesh-wide metrics (avg, max)
   - Send to controller
4. Controller publishes to Prometheus endpoint
5. Metrics available for monitoring/alerting


## MESH METRICS REFERENCE

### Zone: rack.mesh (Multi-host aggregate)
- `ghostlink_sigma_fraction{roi="rack.mesh"}` - Quality metric (0-1)
- `ghostlink_window_samples{roi="rack.mesh"}` - Samples in current window
- `ghostlink_mesh_temp_avg` - Average temperature across mesh
- `ghostlink_mesh_temp_max` - Maximum temperature in mesh
- `ghostlink_peer_count` - Active peer count

### Zone: rack.core (Local only)
- `ghostlink_sigma_fraction{roi="rack.core"}` - Local quality
- `ghostlink_window_samples{roi="rack.core"}` - Local samples
- `ghostlink_cpu_temp_c{zone="core"}` - Local CPU temperature

```bash
# Restart if needed
./run_venv.sh down
./run_venv.sh up
./run_venv.sh mesh
```

### High network traffic
Edit `gl_peer_mesh.py`:
- Change sampling interval: `time.sleep(1)` → `time.sleep(5)`
- Change discovery interval: `MESH_DISCOVERY_INTERVAL = 30` → `60`
