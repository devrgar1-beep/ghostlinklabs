## Installation & Setup

### Prerequisites
- Python 3.8+ (required)
- Docker (optional, for containerization)
- Wolfram Mathematica/Engine (optional, for symbolic computation)
- Node.js/npm (optional, for VS Code extension)

### Installation Steps
1. **Clone Repository**
   ```bash
   git clone https://github.com/ghostlink/hybrid-triad.git
   cd hybrid-triad
   ```

2. **Install Python Dependencies**
   ```bash
   pip install -e .                    # Minimal (sovereign)
   pip install -e ".[full]"           # Full triad capabilities
   ```

3. **Build VS Code Extension** (Optional)
   ```bash
   cd .vscode/link-agent
   npm install && npm run compile
   ```

4. **Activate Triad Synergy**
   ```bash
   ./activate_triad_synergy.sh
   ```
