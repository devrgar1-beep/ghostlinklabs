# GhostLink Artifacts Checklist (v1.0)

- Orchestrator code (commit hash, license)
- Motif library (alpha, beta, loop transforms)
- Evaluators (task harness, judges, rubric)
- Trace store + audit tools (content-addressed, signatures)
- Consensus module (PBFT/HotStuff variant), tests
- Config manifests (topology, λ settings, annealing schedule)
- Repro scripts (seeded runs, ablations, CI harness)
- Raw results (CSV/Parquet), summaries, CIs
- Safety gates (reproduction quotas, kill switch, incident playbooks)
