## 📋 Step-by-Step Installation

### 1. Install GhostLink Extension
```
VS Code → Ctrl+Shift+X → ... → Install from VS Code...
Navigate to: vscode-extensions/ghostlink-vscode
Select folder → Install
```

### 2. Install HTTP API Extension
```
Extensions Panel → Search: vscode-http-api
Install the extension
```

### 3. Start HTTP API Service
```
Command Palette (Ctrl+Shift+P)
Type: VSCode HTTP API: Start
Press Enter
```

### 4. Verify Everything Works

## 🔧 Troubleshooting

**If extensions don't install:**
- Make sure VS Code is fully closed and reopened
- Check that the extension folder path is correct
- Try installing from VS Code menu again

**If HTTP API doesn't start:**
- Ensure the vscode-http-api extension is installed
- Check Command Palette for the start command
- Look for error messages in VS Code output panel

**If commands don't work:**
- Run `./verify_vscode_integration.sh` to check status
- Check VS Code settings are configured
- Restart VS Code completely
