## PART 5: MEMORY SYSTEMS

### Memory Traces (ρ and κ)

**ρ (rho) - Scar Density**
- Tracks failure history
- Exponential decay: `ρ(t+1) = 0.95 × ρ(t) + (1 if SCAR else 0)`
- High ρ → avoid this area

**κ (kappa) - Compost Density**
- Tracks recyclable material
- Exponential decay: `κ(t+1) = 0.9 × κ(t) + (1 if COMPOST else 0)`
- High κ → fertile ground for new ideas

**Why Exponential Decay?**
- Recent failures matter more than old ones
- System gradually "forgets" old pain
- Allows learning without permanent scarring

### Legacy DAG (Directed Acyclic Graph)

**Purpose:** Track state lineage

Every state transition creates a node in the DAG:
```
Generation 0: {void: 1024, delta: 0, ...} → hash: a3f9e2
           ↓
Generation 1: {void: 1000, delta: 24, ...} → hash: b2c4d1
           ↓
Generation 2: {void: 980, delta: 20, sigma: 4, ...} → hash: c5e7a9
```

**Benefits:**
- Can trace any state back to its origin
- Detect patterns in evolution
- Verify integrity (hash chain)
- Replay history deterministically

### Continuity Mass

**Formula:** `C(t) = Σ(t) + 0.9 × C(t-1)`

This is a **discounted sum** of SIGMA states over time.

**Interpretation:**
- High continuity mass = stable knowledge
- Sudden drop = knowledge collapse
- Gradual growth = learning
- Plateau = equilibrium

## PART 9: COMPLETE PHYSICS

### Spawn Phase (VOID → DELTA)

**Purpose:** Generate new hypotheses

**Formula:**
```
P(VOID → DELTA) = base_rate × (1 + boost × compost_neighbors / 8)

Default values:
- base_rate = 0.05 (5% chance)
- boost = 0.8 (80% increase per compost neighbor)
```

**Example:**
- Cell has 3 COMPOST neighbors
- P = 0.05 × (1 + 0.8 × 3/8) = 0.05 × 1.3 = 0.065 (6.5%)

**Intuition:** Areas with many failures (COMPOST) are fertile for new ideas.

### Collapse Phase (DELTA → {SIGMA, SCAR, COMPOST})

**Purpose:** Resolve hypotheses

**Step 1: Calculate Energies**
```
coherence = σ_neighbors/8 - 0.25 × scar_neighbors/8
pain = ρ[i,j] + scar_neighbors/8
entropy = unique_neighbor_states / 5

E_σ = w_coherence × coherence + w_pain × pain
E_scar = 0.3 × pain - 0.2 × coherence  
E_compost = w_entropy × entropy - 0.1 × coherence

Default weights:
- w_coherence = 1.0 (favor coherence)
- w_pain = -0.5 (penalize pain)
- w_entropy = 0.3 (slight entropy bonus)
```

**Step 2: Softmax**
```
temperature = 1.0 (controls randomness)

probs = softmax([E_σ, E_scar, E_compost] / temperature)
```

**Step 3: Sample**
```
outcome = categorical_sample(probs)
new_state = [SIGMA, SCAR, COMPOST][outcome]
```

**Example:**

Cell with:
- 5 SIGMA neighbors, 1 SCAR neighbor
- ρ = 0.1 (low scar density)
- 3 unique neighbor states

```
coherence = 5/8 - 0.25×1/8 = 0.594
pain = 0.1 + 1/8 = 0.225
entropy = 3/5 = 0.6

E_σ = 1.0×0.594 + (-0.5)×0.225 = 0.481
E_scar = 0.3×0.225 - 0.2×0.594 = -0.051
E_compost = 0.3×0.6 - 0.1×0.594 = 0.121

probs = softmax([0.481, -0.051, 0.121])
      = [0.63, 0.12, 0.25]

→ 63% chance SIGMA
→ 12% chance SCAR
→ 25% chance COMPOST
```

### Recycle Phase (COMPOST → DELTA)

**Purpose:** Reuse failed material

**Formula:**
```
P(COMPOST → DELTA) = base_rate × 
    (1 + entropy_factor × entropy - coherence_penalty × coherence)

Default values:
- base_rate = 0.1 (10% chance)
- entropy_factor = 0.5 (entropy helps recycling)
- coherence_penalty = 0.3 (coherence inhibits recycling)
```

**Example:**
- entropy = 0.8 (diverse neighbors)
- coherence = 0.3 (some order)

```
P = 0.1 × (1 + 0.5×0.8 - 0.3×0.3)
  = 0.1 × (1 + 0.4 - 0.09)
  = 0.1 × 1.31
  = 0.131 (13.1%)
```

**Intuition:** Recycling works best in diverse, less ordered areas.

### Memory Trace Updates

**After each step:**
```
ρ[i,j] = ρ[i,j] × decay_ρ + (1 if state=SCAR else 0)
κ[i,j] = κ[i,j] × decay_κ + (1 if state=COMPOST else 0)

Default decays:
- decay_ρ = 0.95 (5% forgetting per step)

```

**Result:** Traces decay exponentially but can be reinforced by repeated failures.
