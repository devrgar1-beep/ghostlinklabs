═══════════════════════════════════════════════════════════════════
  PIPELINE STAGES (DETAILED)
═══════════════════════════════════════════════════════════════════

P-01 MAP (Parse Input)
  Stage 1: skeleton  - Extract basic structure
  Stage 2: lex       - Break into tokens
  Stage 3: ast       - Build syntax tree
  Stage 4: normalize - Standardize format
  Stage 5: index     - Make searchable

P-02 CLEANSE (Clean Data)
  Stage 1: trim      - Remove whitespace/junk
  Stage 2: dedup     - Remove duplicates
  Stage 3: validate  - Check against rules
  Stage 4: sanitize  - Remove dangerous content

P-03 SURGE (Speed Up)
  Stage 1: batch     - Group similar items
  Stage 2: parallel  - Execute simultaneously
  Stage 3: throttle  - Control rate
  Stage 4: optimize  - Minimize overhead

P-04 LOCK (Apply Limits)
  Stage 1: check_caps      - Verify permissions
  Stage 2: enforce_scope   - Apply boundaries
  Stage 3: rate_limit      - Control frequency

P-05 SILENCE (Reduce Noise)
  Stage 1: filter_output - Keep important only
  Stage 2: suppress_logs - Reduce verbosity
  Stage 3: mute_events   - Stop notifications

═══════════════════════════════════════════════════════════════════
  PYTHON CODE SNIPPETS
═══════════════════════════════════════════════════════════════════

Load Kernel
-----------
import json
with open('kernel.json') as f:
    kernel = json.load(f)

Get Agent by ID
---------------
def get_agent(kernel, agent_id):
    return next(a for a in kernel['agents'] if a['id'] == agent_id)

agent_1 = get_agent(kernel, 1)
print(agent_1['role'])  # 'Recursive'

Get Pipeline by Name
--------------------
def get_pipeline(kernel, name):
    return next(p for p in kernel['pipelines'] if p['name'] == name)

cleanse = get_pipeline(kernel, 'CLEANSE')
print(cleanse['purpose'])

List All Agent Roles
--------------------
roles = [a['role'] for a in kernel['agents']]
print(roles)

List All Pipelines
------------------
pipelines = [p['name'] for p in kernel['pipelines']]
print(pipelines)

Find Agents by Duty
-------------------
def find_agents_by_duty(kernel, duty):
    return [a for a in kernel['agents'] if duty in a['duties']]

validators = find_agents_by_duty(kernel, 'verify')

PROBLEM: Want to rollback changes
SOLUTION: Use Agent 51 (Snapshot) before, Agent 50 (Recovery) after
