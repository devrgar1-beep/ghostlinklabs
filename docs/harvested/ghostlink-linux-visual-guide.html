STEP 4

Boot from USB (ASUS Z790)

🔧 BIOS Settings

1. Enter BIOS: Press DEL key during boot

2. Find Boot Menu: Usually F8 key

3. Select: Your USB drive

4. Boot: Press Enter

⚠️ IMPORTANT: Disable Secure Boot in BIOS first!
Advanced → Security → Secure Boot → Disabled

STEP 7

Install GhostLink

Open Terminal (Super key + T) and paste:

# Update system
sudo apt update && sudo apt upgrade -y

# Install Python and Git
sudo apt install python3 python3-pip git -y

# Clone GhostLink
git clone https://github.com/yourusername/ghostlinklabs.git
cd ghostlinklabs

# Install dependencies
pip3 install -r requirements.txt

# Run GhostLink
python3 ghostlink_boot.py
🎯 GhostLink is now running on Linux!

🆘 If Something Goes Wrong

Common Fixes:

Black screen: Press Ctrl+Alt+F2 for terminal

No WiFi: Use ethernet cable first

Can't boot: Press F8, choose Windows

Graphics issues: Boot with "Safe Graphics" option

Remember: You can always boot back to Windows!
