## 🔍 Extraction Method

### Search Algorithm
1. **Multi-source scanning:** Downloads folder, wiki root, git repository
2. **Keyword-based relevance:** Query split into keywords, scored by matches
3. **Recursive traversal:** All subdirectories scanned for markdown files
4. **Code block extraction:** Fenced blocks with language detection
5. **Deduplication:** SHA-256 hash-based duplicate prevention
6. **Safe writes:** Sanitized filenames, UTF-8 encoding, workspace scoping

## 🎓 Key Insights

### What Worked Well
- **Multi-source scanning** found content across multiple locations
- **Keyword-based relevance** effectively matched queries to content
- **Recursive traversal** ensured comprehensive coverage
- **State tracking** enabled resumable extraction
- **Deduplication** prevented redundant file creation

### Lessons Learned
- Large markdown files (GHOSTLINK_COMPLETE_ARTIFACT.md: 275KB) contain extensive code
- Code blocks often include theory alongside implementation
- Same implementation may appear in multiple source documents
- Inline code snippets provide valuable context
- Source file metadata crucial for attribution
